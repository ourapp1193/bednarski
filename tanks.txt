Neural Network Tank Game
JavaScript, Socket.io, p5.js, Custom ML

Multiplayer tank game with physics-based shooting. A 2-layer neural network predicts shot trajectories and adapts to wind/distance using supervised learning. Features include:

NN smart aiming (Leaky ReLU)

Real-time sync via Socket.io

Live loss graph & NN viz

Projectile arcs with wind/gravity

Custom backprop with momentum

Explosions, life bars, and responsive UI

Skills:
Multiplayer networking, ML from scratch, physics simulation, real-time visualization
