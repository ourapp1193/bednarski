React app detects O-ring flaws via camera. Uses local YOLOv5 ONNX model with onnxruntime-web (WASM backend, SIMD, 4 threads) for mobile. Worker loads model with fallback, runs inference asynchronously. Video frames preprocessed to Float32 tensor (normalized RGB), input size fixed. Outputs parsed into boxes with confidence filtering and NMS. Calibration allows physical size measurement in mm. Drawing overlays boxes on canvas with color-coded status and size labels. Runs inference every 200ms, manages processing state to prevent overlap. Switches camera front/back. Error handling and performance logging included.
