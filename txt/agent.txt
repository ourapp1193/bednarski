Express API that fetches job listings from Jooble and customizes a base CV for each offer using a local Ollama AI model(via HTTP).Receives search query and location, fetches jobs, and generates personalized CVs(txt format) by prompting the model to adapt a predefined CV.Each CV is saved to disk and returned alongside job info.Uses dotenv for config, logs requests, handles retries and timeouts.Supports static file access to saved CVs.Built -in error handling and development diagnostics.
