Web app with canvas lets users draw curves, then fits a polynomial and trains a neural network using TensorFlow.js. Polynomial regression (degree 3) is computed manually (matrix math) and rendered on canvas. Neural net (2 hidden layers, ReLU) is trained to fit the same data, visualized via animated "rider" and Chart.js loss graph. Uses dense model with MSE loss and Adam optimizer. Training is done live in-browser with loss logged per epoch. Supports mouse/touch input. UI includes fixed loss chart and canvas drawing area.
