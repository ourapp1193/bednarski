Project 1: WebSocket Chat Application

- Description:
  Developed a full-stack real-time chat application using Node.js, JavaScript, and WebSockets. Users can sign up, log in, send messages, block/unblock users, and upload avatars. Chat history and user info stored in SQLite3.

- Key Features:
  • Real-time messaging with WebSockets
  • RESTful API for account management
  • Circular avatar upload + image cropping
  • Dynamic frontend with JavaScript
  • Message filtering, blocking logic
  • Deployed on Glitch and Render

- Skills Used:
  JavaScript, Node.js, WebSockets, SQLite3, CSS transitions, frontend-backend integration
